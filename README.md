# Legacy Group Washington, D.C. Tour Guide

A mobile-first travel companion for Emmanuel Baptist Church's Legacy Group, using GitHub Pages.

Status: Preview until the full itinerary, hotel, bus and group contacts have been provided and verified.

Brand: Dark Teal #044F56, Gold #FFAE05, Near Black #232323, Teal #7BC2C8, Cream #EDE0CA, White #FFFFFF. Large display: Meno Banner; UI and body: Montserrat.

PDF: 5.5 × 8.5 inch booklet pages, quarter-inch margins and QR codes, no printed URLs.

This guide intentionally omits a Return to Meeting Point feature.
